A shelf of small Python tools, each doing exactly one thing.

No framework, no dependencies you didn't ask for, no 40-file project for a job that fits in one. Clone it, read the one script you need, run it.

zsh — pyth0nScr1pts
$git clone https://github.com/yourname/pyth0nScr1pts.git
$ls
rename_batch.py   img_squeeze.py   dupe_finder.py   csv_diff.py
$python3 dupe_finder.py ~/Downloads

scripts

Everything here started as a one-off fix for a real annoyance. Kept in if it turned out to be useful more than once.

rename_batch.py

Batch renamer with a dry-run mode

Renames files in a folder against a pattern — dates, sequence numbers, find-and-replace — and shows you the diff before touching anything.

stdlib only~90 linesupdated Jul 2026
img_squeeze.py

Recursive image compressor

Walks a directory tree and re-encodes JPEG/PNG images to a target size ceiling, preserving the folder structure and original files.

needs Pillow~120 linesupdated Jun 2026
dupe_finder.py

Find duplicate files by content, not name

Hashes files rather than comparing filenames, so it catches copies that got renamed along the way. Prints a list, deletes nothing on its own.

stdlib only~60 linesupdated May 2026
csv_diff.py

Row-level diff for two CSVs

Compares two versions of a spreadsheet export by a key column and reports which rows were added, removed, or changed, and which fields moved.

stdlib only~140 linesupdated Mar 2026
port_watch.py

Tiny local port monitor

Polls a list of local ports and pings you (terminal bell or a webhook) the moment something starts or stops listening.

stdlib only~50 linesupdated Feb 2026

install

There's no package to install. Each script is self-contained — copy the one you want, or clone the whole shelf.

# grab everything
git clone https://github.com/yourname/pyth0nScr1pts.git
 
# or just one script
curl -O https://raw.githubusercontent.com/yourname/pyth0nScr1pts/main/dupe_finder.py
 
# most need nothing beyond the standard library
python3 dupe_finder.py --help

one file, one job

If a script starts needing a second file, it gets split into its own repo instead.

stdlib first

Third-party dependencies are called out explicitly in the script's own docstring, not hidden in a requirements file.

dry-run where it matters

Anything that renames, deletes, or overwrites shows you what it's about to do first.

read before you run

Every script is short enough to read top to bottom in a couple of minutes. That's on purpose.

about

This shelf gets a new script whenever an afternoon problem is annoying enough to fix properly. Nothing here is trying to be a framework or a product — if you find one useful, that's the whole point. Issues and pull requests for small, focused scripts are welcome; anything that needs its own dependency tree probably belongs in its own repository instead.
