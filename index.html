install

There's no package to install. Each script is self-contained, so copy the one you want or clone the whole shelf.

  1. Check that you have Python 3

    Any recent Python 3 release works. If this prints a version starting with 3, you're set.

    python3 --version

  2. Get the scripts

    Clone everything if you want to browse, or pull down a single file.

    git clone https://github.com/yourname/pyth0nScr1pts.git

    or just one script

    curl -O https://raw.githubusercontent.com/yourname/pyth0nScr1pts/main/dupe_finder.py

  3. Read the help, then run it

    Every script explains its options with --help. Scripts that need a package say so at the top of the file.

    python3 dupe_finder.py --help

one file, one job

If a script starts needing a second file, it gets split into its own repo instead.

stdlib first

Third-party dependencies are called out in the script's own docstring, not hidden in a requirements file.

dry-run where it matters

Anything that renames, deletes, or overwrites shows you what it's about to do first.

read before you run

Every script is short enough to read top to bottom in a couple of minutes. That's on purpose.

about

This shelf gets a new script whenever an afternoon problem is annoying enough to fix properly. Nothing here is trying to be a framework or a product. If you find one useful, that's the whole point.

Issues and pull requests are welcome. A good contribution usually looks like this:

  • A single file that solves one specific, recurring problem.
  • Standard library only, or one clearly named dependency.
  • A --help message and a dry-run mode if it changes files.
  • Short enough that someone can read it before they run it.
